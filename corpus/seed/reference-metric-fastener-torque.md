# Metric fastener torque reference

Dry-thread values for property class 8.8 steel bolts into steel, in newton
metres. Reduce by 25 percent for lubricated threads and by 40 percent for
aluminium tapped holes.

| Thread | Class 8.8 | Class 10.9 | Class 12.9 |
|--------|-----------|------------|------------|
| M4     | 3.0       | 4.4        | 5.1        |
| M5     | 6.0       | 8.7        | 10.2       |
| M6     | 10.2      | 15.0       | 17.5       |
| M8     | 24.6      | 36.1       | 42.3       |
| M10    | 48.6      | 71.4       | 83.6       |
| M12    | 85.0      | 125.0      | 146.0      |
| M16    | 210.0     | 309.0      | 361.0      |

## Notes on use

Torque is a proxy for bolt stretch, and a poor one: as little as 10 percent of
applied torque reaches the joint as clamp load in a dry, corroded thread. Where
clamp load matters, prefer angle-controlled tightening or direct bolt-stretch
measurement.

Re-using a class 12.9 bolt that has been torqued to yield is not permitted.
